Instrucciones de integración de la pecera

1. Copia los archivos necesarios a tu proyecto web

   Debes copiar la carpeta `js/` completa y los ficheros de estilo si quieres usar los estilos existentes.
   - js/app.js
   - js/animation.js
   - js/fish.js
   - js/water.js
   - js/bubbles.js
   - js/audio.js
   - style.css

2. Añade el contenedor de la pecera en tu HTML

   Dentro de tu página HTML, coloca un elemento de contenedor con el id `aquarium-root` donde quieras que aparezca la pecera.

   Ejemplo mínimo:

   <div id="aquarium-root" style="width:100%;max-width:720px;height:420px;margin:24px auto;min-height:320px"></div>

   Si no incluyes `#aquarium-root`, el script creará la pecera dentro de `document.body`.

3. Añade los botones de control (opcional)

   Para controlar el nivel de agua con botones + y - añade esto en tu HTML:

   <div class="aquarium-controls" style="display:flex;justify-content:center;gap:16px;margin-top:16px">
     <button id="minus">-</button>
     <button id="plus">+</button>
   </div>

   El script ya está preparado para enlazar esos botones de forma automática.

4. Incluye los archivos CSS y JavaScript

   En el `head` de tu HTML, enlaza `style.css`:

   <link rel="stylesheet" href="style.css">

   Justo antes de `</body>`, añade el script principal como módulo:

   <script type="module" src="js/app.js"></script>

   Asegúrate de que la ruta `js/app.js` es correcta desde la ubicación de tu HTML.

5. Estructura recomendada del HTML completo

   <!doctype html>
   <html lang="es">
   <head>
     <meta charset="utf-8">
     <meta name="viewport" content="width=device-width,initial-scale=1">
     <title>Tu página con pecera</title>
     <link rel="stylesheet" href="style.css">
   </head>
   <body>
     <div id="aquarium-root" style="width:100%;max-width:720px;height:420px;margin:24px auto;min-height:320px"></div>
     <div class="aquarium-controls" style="display:flex;justify-content:center;gap:16px;margin-top:16px">
       <button id="minus">-</button>
       <button id="plus">+</button>
     </div>
     <script type="module" src="js/app.js"></script>
   </body>
   </html>

6. Cómo controlar la pecera desde JavaScript

   El script crea un objeto global `window.aquarium` cuando la página carga.
   Puedes usarlo desde cualquier otro script después de la carga de la página.

   Ejemplos:

   - Cambiar el nivel de agua directamente:
     window.aquarium.setWaterLevel(60)

   - Subir o bajar el agua:
     window.aquarium.changeWater(5)
     window.aquarium.changeWater(-5)

   - Usar la pecera como indicador de puntuación:
     window.aquarium.setScore(puntos, maxPuntos)
     // Ajusta el nivel de agua según la puntuación

   - Controlar el pez:
     window.aquarium.fish.feed()
     window.aquarium.fish.die()
     window.aquarium.fish.happy()
     window.aquarium.fish.scared()

7. Integración en otro proyecto existente

   - Copia la carpeta `js/` y `style.css` a la carpeta pública de tu proyecto.
   - Ajusta las rutas en el HTML si tu estructura es diferente.
   - Coloca `#aquarium-root` en el lugar donde quieras mostrar la pecera.
   - Si tu proyecto usa un gestor de rutas o build, asegúrate de que el archivo `js/app.js` se sirve como ES módulo.

8. Consejos prácticos

   - Si tu página ya tiene CSS global, puedes eliminar o ajustar el `style.css` para que no interfiera con otros estilos.
   - Si quieres ocultar los botones, simplemente no incluyas el bloque de controles y usa la API `window.aquarium` desde tu propio código.
   - Para integrarlo como widget en una página de juego, añade solo el `div#aquarium-root` y el script; los controles pueden quedar en otra parte de tu interfaz.

9. Ejemplo rápido para un juego

   1. Añade el contenedor de la pecera.
   2. Carga `style.css` y `js/app.js`.
   3. Cuando actualices la puntuación del juego, llama:
      window.aquarium.setScore(score, maxScore)

   De esa forma el agua sube o baja según la puntuación sin añadir más elementos HTML.

Fin de las instrucciones.
