Instrucciones de integración del marcador de acuario

1. Copia los archivos a tu proyecto web

   - js/app.js
   - js/animation.js
   - js/fish.js
   - js/scene.js
   - js/water.js
   - js/bubbles.js
   - js/audio.js
   - style.css

   La pecera se crea por código (no necesita SVG en el HTML): sólo se
   necesita un contenedor con id `aquarium-root`.

2. Contenedor HTML

   <div id="aquarium-root" style="width:100%;max-width:760px;height:460px"></div>

   Si el contenedor no existe, el widget se crea dentro de document.body.

3. Carga los estilos y el módulo

   <link rel="stylesheet" href="style.css">
   ...
   <script type="module" src="js/app.js"></script>

   Ajusta las rutas según tu estructura. app.js es un ES módulo.

4. Modelo de puntuación

   Puntuación  -20  → agua 0%   (el pez muere: fin del juego)
   Puntuación    0  → agua 40%  (partida sana)
   Puntuación  +80  → agua 100% (el agua satura)

   Al superar +80 la puntuación sigue creciendo de forma visible: el pez
   evoluciona (dorado, más grande, corona a +280) y aparecen peces
   acompañantes (cada +60 puntos, máximo 4). Si la puntuación baja, esos
   hitos se pierden. Un número grande de puntos acompaña al tanque.

   Al llegar a −20 el pez muere y el widget queda congelado (el marcador no
   reacciona a más puntuaciones) hasta que se llame a reset() o el usuario
   pulse "Jugar otra vez".

5. Controlar el marcador desde JavaScript

   El script crea `window.aquarium` al cargar la página:

   - window.aquarium.setScore(puntos)       // aplica el modelo completo
   - window.aquarium.changeScore(delta)     // ajuste relativo
   - window.aquarium.reset()                // partida nueva
   - window.aquarium.setVolume(0.8)         // volumen general 0..1
   - window.aquarium.setMuted(true)         // silencio

   Reloj de "minuto sin responder":

   - window.aquarium.word()                 // CON CADA palabra nueva: el
                                            // contador vuelve a cero y sigue
                                            // andando (despierta si estaba
                                            // detenido por el minuto cumplido)
   - window.aquarium.setIdleClock({         // configuración (opcional)
       seconds: 60,                         //   segundos de gracia (min 5)
       penalty: 5 })                        //   puntos que resta al llegar al
                                            //   minuto (0 = solo avisa)

   - Si el minuto se cumple, el widget dispara el evento 'idle' y se detiene
     hasta la siguiente palabra (una única vez por palabra perdida).
   - Al terminar la partida (agua a 0 / pez muerto) el contador queda parado
     de forma definitiva; solo reset() o "Jugar otra vez" lo reactiva.
   - Evento 'idleTick' cada segundo con { elapsed, max } para pintar un
     contador en tu juego si lo quieres ahí en vez de en el widget.
   - window.aquarium.fish.happy()           // celebra
   - window.aquarium.fish.scared()          // se asusta
   - window.aquarium.fish.feed()            // alias de happy

   Compatibilidad con la versión anterior (agua directa):

   - window.aquarium.setWaterLevel(65)
   - window.aquarium.changeWater(-10)

   Eventos (window.aquariumInstance):

   - .on('level', nivel => ...)             // 0..100 en cada frame
   - .on('fishstate', estado => ...)        // feliz, preocupado, boquea,
                                            // cae, asustado, muerto
   - .on('milestone', m => ...)             // {kind:'tier'|'companion', value}
   - .on('gameover', puntuacion => ...)     // al ahogarse el pez

6. Ejemplo con un juego

   // al terminar una ronda
   window.aquarium.setScore(score);

   // al perder una vida
   window.aquarium.changeScore(-5);

   // al terminar la partida
   window.aquarium.on('gameover', finalScore => mostrarPantalla(finalScore));

7. Consejos

   - Si tu página ya tiene CSS general, puedes ajustar style.css para que
     no interfiera.
   - El sonido se inicializa en el primer gesto del usuario (políticas de
     autoplay) y se silencia con el botón 🔊 o audio.setMuted(true).
   - Si quieres ocultar los controles de la demo, no añadas los botones;
     la API sigue funcionando.
